# 対応範囲と制限

[English](compatibility.en.md)

GitHubのリポジトリ内のMarkdown文書と、Qiitaの記事本文を主な対象にしています。GitHubのコメント欄などは、同じ文章でも改行やリンクの扱いが異なります。実サイトの表示や動作の再現を目指して開発していますが、一部の記法や表示に差異があります。

## 表示方式

GitHub／Qiitaの選択とは別に、Markdownを表示に変換する方式を切り替えられます。この文書では、画面の表示に合わせて次の名前を使います。

| 名前 | 内容 |
| --- | --- |
| 独自エンジン | MDV独自の変換方式。GitHub Flavored Markdown（GFM：GitHubで使われるMarkdownの拡張記法）を基本に、Qiitaなどの独自記法に対応 |
| 公開実装エンジン | GitHub／Qiitaが公開している変換プログラムを利用する、両エンジン同梱版・公開実装利用版で使用可能 |

両エンジン同梱版では「表示 → 公開実装エンジンを使用」で切り替えます。初期設定は公開実装です。選択は全タブ共通で、次回起動時にも引き継ぎます。独自エンジン版・公開実装利用版では方式が固定され、切り替えメニューは表示しません。別版の設定を引き継いだ場合も、その版で利用できる方式を選びます。

画面下の処理時間（ms）は、表示の切替から完了までにかかった時間です。

公開実装の変換に失敗した場合はエラーを表示します。両エンジン同梱版では、チェックを外して独自エンジンを選べます。

以下は「独自エンジン」「公開実装エンジン」「両エンジン共通」に分けて説明します。

## 独自エンジン

### 記法の対応

この表は独自エンジンだけを対象にしています。GitHub／Qiitaは、右上で選択する記法を表します。

| 記法 | GitHub | Qiita |
| --- | --- | --- |
| 見出し、リスト、引用、表、タスクリスト、脚注 | 対応 | 対応 |
| `~~取り消し線~~` | 取り消し線 | 取り消し線 |
| `~取り消し線~` | 取り消し線 | 通常の文字 |
| 段落内の通常改行 | 同じ段落としてつなぐ | 改行を表示 |
| `> [!NOTE]` などのアラート | 補足枠 | 通常の引用 |
| `:::note info`、`warn`、`alert` | 通常の文字 | 補足枠。リスト内にも対応。引用の中は対象外 |
| コードの `言語:ファイル名` 指定 | ファイル名は表示しない | ファイル名を表示 |
| コードの `diff_言語` 指定 | 通常のコード | 差分と構文を色分け |
| 単独のWebページのリンク | リンク | リンクカードの枠とアドレス |
| `:emoji:`、`@username` | 絵文字、GitHubのプロフィールへのリンク | 絵文字、Qiitaのプロフィールへのリンク |
| HTML（Webページの記述形式）の折りたたみや表 | 許可した要素に対応 | 許可した要素に対応 |

表示例は「ヘルプ → サンプルを開く」で確認できます。

文書先頭の `---` で囲んだYAML設定項目は表として表示します。GitHubモードでは公開実装エンジンも対応しています。100,000文字を超えるコードブロックは色分けを省略します。

## 公開実装エンジン

GitHub／Qiitaの公開実装に基づいて変換します。上の独自エンジンの対応表は適用されず、細かな記法の解釈が異なる場合があります。

| 記法の選択 | 主な対応 |
| --- | --- |
| GitHub | 公開実装による変換に加え、アプリでは表、タスクリスト、脚注、アラートを有効にしています |
| Qiita | 公開実装による補足枠、ファイル名付きコード、脚注などを表示します |

GitHubのコード色分けは、100,000文字を超える場合に省略します。Qiitaのコード色分けは公開実装に従います。

公開されたプログラムと、実際のサイトで動く版や設定は同じとは限りません。数式・図や、表示できない内容については、次の共通事項も適用されます。

## 両エンジン共通

### 見た目と操作

GitHub／Qiitaそれぞれに合わせた書式を、両エンジンに適用します。見出しのリンクマークは、見出しにマウスを重ねたとき、またはキーボードでリンクを選択したときに表示します。脚注参照は `[1]` の形式で表示します。

コードの色分けは、実際のサイトと異なる場合があります。

Qiitaのコードの色分けは配布版によって異なる場合があります。言語指定は `PowerShell` と `powershell` のどちらでも認識します。

### 数式と図

数式は `$...$`、`$$...$$`、`math` と指定したコードブロックなどで記述します。例えば次のコードブロックは、独立した行の数式として表示します。

````markdown
```math
E = mc^2
```
````

Qiitaでは、見出し・リンク内の数式や、区切り記号のないTeX環境は数式として表示しません。

GitHubでは `\$x$` も数式として表示されます。リンクや通常のコード内、強調・HTML要素をまたぐ記述、改行を含むインライン数式は数式として表示しません。数式の記号をそのまま扱うには、ドル記号の内側をバッククォートで囲む形式か、`math` コードブロックを使ってください。

図は `mermaid` と指定したコードブロックに記述します。マインドマップにも対応します。文字の配置や線の形は、実際のサイトと異なる場合があります。

PlantUML、GeoJSON・TopoJSONによる地図、STL（立体形状データの形式）の立体モデルは描画しません。

### サイトと異なる点

| 項目 | 制限 |
| --- | --- |
| 見た目 | フォント、余白、色、絵文字の形はサイトと一致しない場合があります |
| リンクカード・埋め込み | Qiitaでは通常URLを表示し、指定時のみタイトル・サムネイルを取得・保存してオフライン表示できます。動画、投稿、スライドなどの埋め込みは再現しません |
| GitHub固有の参照 | `#123` のIssue・プルリクエスト参照、コミットやリポジトリ固有のリンク先を解決しません |
| 文書内のHTML | スクリプト、フォーム、外部ページの埋め込みなどを除去し、許可した要素・属性だけを表示します。GitHubでは `<font>` による色指定や本文の `style` による文字色指定を除去します。Qiitaでは `<font color="…">` など一部の指定を許可します |
| 保存した外部画像 | GitHubの公開リポジトリとQiitaの画像を、明示的な操作で取得・保存してオフライン表示できます。GitHubでは入力した文書URLを基準に相対パスを解決します。認証が必要な非公開リポジトリの取得には対応しません |
| ローカル画像・リンク | 文書のフォルダ内に制限します。具体例は[使い方と設定](portable.md#画像とリンク)を参照してください |

### 読み込める文書と上限

文字コードはUTF-8（Unicodeの文字コード）、文字コードを示す印付きのUTF-16/32、Shift_JIS（Windowsのコードページ932）に対応します。この印をBOM（Byte Order Mark）と呼びます。印がない場合はUTF-8として読み、読めないときだけShift_JISを試します。

容量の単位MiBは、1 MiB＝1,048,576バイトです。

| 対象 | 上限 |
| --- | --- |
| 文書 | 16 MiB、かつ約419万文字まで。絵文字などは複数文字分として数える場合があります |
| 画像 | 1ファイル32 MiBまで |
| GitHub／Qiitaの画像保存 | 1文書128画像、合計256 MiBまで |
| Mermaid | 1文書40個、1個あたり50,000文字・500本の線まで |

上限内でも、複雑な図や数式は表示に時間がかかる場合があります。

## 検証の範囲

記法の変換、主要な表示要素、画面操作をテストしています。比較対象は固定した公開実装・公開ページの観測値であり、実サイト全体や将来の変更との一致を保証しません。比較手順は[ビルドと検証](development.md)を参照してください。
