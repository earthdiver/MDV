# MDV — GitHub / Qiita Markdown Viewer

[English](README.en.md)

GitHubのリポジトリ内のMarkdown文書と、Qiitaの記事本文を読むWindows用アプリです。表、コードの色分け、数式、Mermaid、タブ、目次、検索、印刷・PDF保存に対応します。文書の編集は行いません。

## 主な機能

- GitHub／Qiitaの記法と、2種類の変換エンジンに対応。
- タブ、目次、本文検索、ソース表示、自動再読み込み。
- 表、コードの色分け、数式、Mermaid、ダークテーマ、印刷・PDF保存。
- 文書内の外部画像を取得・保存し、オフライン表示。GitHub相対パス・Qiita CDN画像の追加取得とリンクカード保存にも対応。
- 日本語・英語の画面表示と、EXEの隣に保存するポータブル設定。

## 配布版を選ぶ

| 配布名 | 内容 |
| --- | --- |
| `dual` — 両エンジン同梱版 | 独自エンジンと公開実装エンジンを切り替え可能。初期設定は公開実装。迷った場合はこちら |
| `custom` — 独自エンジン版 | MDV独自の表示方式でGitHub／Qiitaに対応。表示資材はメモリで処理 |

## 使い始める

1. 選んだEXEを、書き込み可能なフォルダに置きます。必要なら `MDV.exe` に改名できます。
2. 起動して「開く」またはドラッグ＆ドロップで文書を開きます。
3. dual／custom版では、右上の「GitHub」「Qiita」で文書に合う記法を選びます。

配布対象は **Windows 11 x64** です。PCにインストール済みの **WebView2 Evergreen Runtime** を使用します。通常は追加インストール不要ですが、WebView2が見つからない場合は[Microsoft公式サイト](https://developer.microsoft.com/microsoft-edge/webview2/)からインストールしてください。基本機能はオフラインで使えます。dual版は初回起動時に資材をディスクへ展開します。custom版は表示資材・サンプル・ライセンスをメモリへ読み込み、資材管理メニューはありません。どちらの版も、ネイティブDLLの展開とWebView2の作業データに一時フォルダを使用します。容量と一時ファイルについては[使い方と設定](docs/portable.md#更新と一時ファイル)を参照してください。

表示言語はWindowsの表示言語が日本語なら日本語、それ以外なら英語になります。「言語 → 自動（システム設定）／日本語／English」で明示的に選択でき、変更は即時に反映され、再起動後も維持されます。

設定はEXEと同じ場所の同名の `.ini` に保存します。例えば `MDV-v0.4.0-dual-win-x64.exe` の設定は `MDV-v0.4.0-dual-win-x64.ini` です。設定も持ち運ぶ場合は両方をコピーしてください。

**GitHub・Qiitaとの完全互換ではありません。** 実サイトの表示や動作の再現を目指して開発していますが、一部の記法や表示に差異があります。GitHub・Qiitaの公式アプリではありません。
