# MDV — GitHub / Qiita Markdown Viewer

[English](README.en.md)

GitHubのリポジトリ内のMarkdown文書と、Qiitaの記事本文を読むWindows用アプリです。表、コードの色分け、数式、Mermaid、タブ、目次、検索、印刷・PDF保存に対応します。文書の編集は行いません。

## 主な機能

- GitHub／Qiitaの記法と、2種類の変換エンジンに対応。
- タブ、目次、本文検索、ソース表示、自動再読み込み。
- 表、コードの色分け、数式、Mermaid、ダークテーマ、印刷・PDF保存。
- Qiitaの画像・リンクカードを指定時にオンラインで取得・保存し、その後はオフライン表示。
- 日本語・英語の画面表示と、EXEの隣に保存するポータブル設定。

## 配布版を選ぶ

| 配布名 | 内容 |
| --- | --- |
| `dual` — 両エンジン同梱版 | 独自エンジンと公開実装エンジンを切り替え可能。初期設定は公開実装。迷った場合はこちら |
| `upstream` — 公開実装利用版 | GitHub／Qiitaが公開している変換実装を利用。エンジンの切り替えなし |
| `custom` — 独自エンジン版 | 外部ライブラリを組み合わせたMDV独自の変換処理。エンジンの切り替えなし |

独自エンジン版は、同じ条件で作成したEXEが他の2版より小さい場合に公開します。使用するエンジンにより、記法の解釈や数式・色分けに差があります。GitHub／Qiitaの選択は、どの版でも可能です。

## 使い始める

1. 選んだEXEを、書き込み可能なフォルダに置きます。必要なら `MDV.exe` に改名できます。
2. 起動して「開く」またはドラッグ＆ドロップで文書を開きます。
3. 右上の「GitHub」「Qiita」で文書に合う記法を選びます。

配布対象は **Windows 10/11 x64** です。実行環境を内蔵し、追加インストールは不要です。基本機能はオフラインで使えます。初回起動では内蔵資材を展開するため、一時フォルダに **1 GB以上** の空き容量が必要です。

表示言語はWindowsの表示言語が日本語なら日本語、それ以外なら英語になります。「言語 → 自動（システム設定）／日本語／English」で明示的に選択でき、変更は即時に反映され、再起動後も維持されます。

設定はEXEと同じ場所の同名の `.ini` に保存します。例えば `MDV-v0.3.0-dual-win-x64.exe` の設定は `MDV-v0.3.0-dual-win-x64.ini` です。設定も持ち運ぶ場合は両方をコピーしてください。

**GitHub・Qiitaとの完全互換ではありません。** 公開実装の利用は実サイトとの一致を保証しません。Qiitaの表示スタイルはMDVの独自実装です。GitHub・Qiitaの公式アプリではありません。
